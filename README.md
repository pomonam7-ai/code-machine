# 오토컷 스튜디오

영상을 넣으면 자동으로 아래 작업을 해서 **완성 MP4**를 만들어 줍니다. 모두 **무료·오프라인**으로 내 PC에서 돌아갑니다.

1. **대본 추출**: 음성 인식(faster-whisper)으로 단어마다 시간을 기록합니다.
2. **1차 컷 편집**
   - 무음 구간 제거: 0.55초 넘게 쉬면 잘라내고, 자연스러운 호흡(0.18초)과 문장 끝 쉼(0.32초)은 남깁니다.
   - 필러워드 제거: "어", "음", "으음" 같은 소리는 항상 자르고, "그…", "저…"처럼 문장 성분일 수도 있는 말은 길게 끌 때만 자릅니다.
   - 컷 지점에는 12ms 페이드를 넣어서 '틱' 소리가 나지 않습니다.
3. **설명 일러스트**: 대본에서 개념 설명, 비교, 변화, 단계 같은 문장을 찾아서 플랫 벡터와 손그림 카툰 스타일 카드를 띄웁니다.
   - 글자는 키워드 1개(7자 이하)만 씁니다. 예: `시간→돈`
   - 카드는 얼굴 반대쪽에 자동으로 놓이고, 톡 튀어나왔다가 사라지는 애니메이션이 들어갑니다.
4. **개인정보 모자이크**: 화면 속 글자를 읽어서(EasyOCR) 아래 정보를 찾으면 그 부분만 모자이크합니다.
   - 전화번호, 휴대폰 번호, 이메일, 주민등록번호, 카드·계좌번호, 주소, 운전면허 번호, 여권 번호, IP 주소
   - 직접 지정한 단어(예: 내 이름)
5. 결과물로 `영상이름_편집본.mp4`와 자막 파일 `영상이름_편집본.srt`가 나옵니다.

## 설치 (처음 한 번)
1. 폴더 압축을 풉니다. 경로에 한글이 없는 곳을 권장합니다. 예: `C:\AutoCutStudio`
2. **install.bat**을 더블클릭합니다. Python이 없으면 자동 설치를 시도합니다. 처음에는 패키지와 모델을 받느라 10~20분쯤 걸립니다.
3. (선택) NVIDIA 그래픽카드가 있다면 **install_gpu.bat**도 실행하세요. 속도가 3~10배 빨라집니다.

## 사용법
- **run.bat**을 더블클릭하면 **브라우저에서 웹앱**이 열립니다. 인터넷 없이 내 PC에서만 동작해요.
  - 검은 창(콘솔)은 닫지 말고 최소화해 두세요. 닫거나 웹 화면의 **⏻ 종료**를 누르면 꺼집니다.
  - **🎬 편집하기**: 📂 영상·폴더 추가 → 옵션 버튼 켜고 끄기 → **▶ 편집 시작**. 결과 표에서 ▶ 보기, 📂 폴더 열기, ✏️ 일러스트 편집 버튼을 쓸 수 있어요.
  - **✏️ 일러스트 편집**: 편집본을 보면서 일러스트 시간·그림·키워드·로고를 바꾸고, 추가하거나 지운 뒤 **🎬 저장하고 다시 만들기**를 누릅니다. 음성 인식과 분석은 다시 하지 않아서 빨라요.
  - **🖼️ 아이콘·로고**: 아이콘 33종을 미리 보고, 로고 이미지를 올리거나 지웁니다.
  - 예전 창 화면이 필요하면 `venv\Scripts\python -m autocut --gui`
- 또는 영상 파일을 **run.bat 아이콘 위에 끌어다 놓아도** 바로 편집이 시작됩니다.
- 결과물은 원본 영상과 같은 폴더에 저장됩니다.

### 투명 배경 일러스트와 로고
- 일러스트는 기본으로 **투명 배경 스티커**로 영상 위에 겹쳐집니다. 흰 테두리와 옅은 그림자가 있어 어떤 화면 위에서도 잘 보여요. 예전처럼 종이 카드 모양을 원하면 옵션에서 **종이 카드**를 고르세요(`--style card`).
- **로고**: `assets/logos` 폴더(또는 웹앱의 ＋ 로고 올리기)에 이미지를 넣으면, 대본에서 그 이름이 나오는 장면에 로고가 자동으로 뜹니다.
  - 파일 이름이 곧 키워드예요. 쉼표로 별칭을 붙일 수 있어요. 예: `유튜브,youtube.png`
  - 흰색 같은 단색 배경은 자동으로 투명하게 바뀝니다. 투명 PNG면 그대로 씁니다.
  - 다른 회사 로고는 사용 권한을 확인하고 쓰세요. 끄려면 **로고 자동 표시** 버튼을 끄거나 `--no-logo`.

### 여러 영상 한 번에 편집하기 (일괄 처리)
- **batch.bat** 아이콘 위에 영상 폴더를 끌어다 놓으면 폴더 안(하위 폴더 포함) 영상을 차례로 모두 편집합니다. 그냥 더블클릭하면 폴더 경로를 묻습니다.
- 프로그램 창에서는 **📁 폴더 선택 (일괄)**을 누르면 됩니다. 영상 여러 개를 직접 골라도 됩니다.
- **이미 편집된 영상은 건너뜁니다.** 중간에 멈추거나 PC를 꺼도 다시 실행하면 남은 영상부터 이어서 합니다.
  - 다시 만들려면 결과 파일을 지우거나 **"처음부터 다시"**를 체크하세요.
  - 작업 폴더의 JSON을 고쳤다면 그 영상만 자동으로 다시 렌더링합니다.
- 한 영상에서 오류가 나도 **다음 영상으로 계속** 진행합니다.
- 끝나면 `오토컷_일괄처리_날짜_시간.csv` 요약 파일이 생깁니다. 엑셀로 열면 영상별 상태(완료/건너뜀/실패/중지), 줄어든 시간, 일러스트·모자이크 개수, 오류 내용을 볼 수 있습니다.
- **결과 저장 폴더**를 지정하면 결과 영상을 한곳에 모읍니다. 하위 폴더 구조는 그대로 유지됩니다. 작업 폴더(`_autocut_work`)는 항상 원본 옆에 생깁니다.

### 결과를 고쳐서 다시 만들기
원본 옆에 `영상이름_autocut_work` 폴더가 생깁니다. 이 폴더의 파일을 고친 뒤 다시 실행하면, 고친 내용이 반영되고 오래 걸리는 단계는 건너뜁니다.

| 파일 | 용도 |
|---|---|
| `transcript.json` | 음성 인식 대본. 오타나 시간을 고칠 수 있습니다. |
| `illustrations.json` | 일러스트 시점, 그림 종류(`concepts`), 키워드(`label`), 로고(`logo`). 항목을 지우거나 고칠 수 있습니다. 웹앱의 ✏️ 일러스트 편집에서 버튼으로 고쳐도 됩니다. |
| `pii.json` | 모자이크 위치와 시간 |
| `cards/` | 생성된 일러스트 미리보기 |

완전히 처음부터 다시 하려면 **"처음부터 다시"**를 체크하세요.

### 일러스트 그림 종류 (`concepts`)
`money` 돈 · `time` 시간 · `idea` 아이디어 · `growth` 상승 · `decline` 하락 · `compare` 비교 · `warning` 주의 · `check` 완료 · `question` 질문 · `person` 사람 · `team` 함께 · `talk` 대화 · `phone` 휴대폰 · `computer` 컴퓨터 · `book` 공부 · `target` 목표 · `steps` 단계 · `heart` 마음 · `home` 집 · `globe` 세계 · `rocket` 시작 · `lock` 보안 · `gear` 원리 · `calendar` 일정 · `search` 분석 · `pie` 비율 · `gift` 혜택 · `car` 자동차 · `food` 음식 · `star` 중요 · `ai` AI · `doc` 문서 · `health` 건강

두 개를 넣으면 `A → B` 관계 그림이 됩니다. 예: `["time","money"]`

## 더 똑똑하게 쓰기 (선택, 모두 무료)
- **문맥을 이해하는 장면 선택**: [Ollama](https://ollama.com)를 설치한 뒤 명령창에서 `ollama pull qwen2.5:7b`를 실행해 두세요. 실행할 때 자동으로 감지해서, 키워드 규칙 대신 로컬 AI가 일러스트를 넣을 장면을 고릅니다.
- **AI가 그린 일러스트**: install_gpu.bat을 실행할 때 Stable Diffusion을 설치하면, 같은 화풍의 그림을 매번 새로 생성합니다. 그래픽 메모리 8GB 이상을 권장합니다.
  - 기본 모델 SDXL-Turbo는 Stability AI Community License를 따릅니다. 연 매출 100만 달러 미만이면 상업적으로 써도 됩니다.
- **명령줄 실행**: `venv\Scripts\python -m autocut 영상.mp4 --keyword 홍길동 --layout right`
  - 폴더 일괄 처리: `venv\Scripts\python -m autocut D:\강의영상 -r --out-dir D:\편집본`
    - `-r` 하위 폴더 포함, `--out-dir` 결과 모으는 폴더, `--redo` 이미 편집된 영상도 다시, `--list` 편집할 목록만 확인
  - 옵션 목록은 `--help`로 볼 수 있습니다.

## 설정 조절
컷 기준, 패딩, 필러 목록, OCR 간격 같은 값은 `autocut/config.py`에서 바꿀 수 있습니다. 작업 폴더의 `settings.json`을 고친 뒤 `--config settings.json`으로 실행해도 됩니다.

- 컷이 너무 많다고 느껴지면 `min_silence`를 0.8 정도로 올리세요.
- 모자이크를 놓치는 장면이 있으면 `ocr_interval`을 0.25로 낮추세요. 대신 느려집니다.

## 알아둘 점
- 모자이크는 화면에 **글자로 보이는** 개인정보만 처리합니다. 얼굴, 번호판, 음성은 처리하지 않습니다. 업로드 전에 꼭 한 번 확인하세요.
- 화면이 빠르게 움직이는 장면에서는 모자이크가 살짝 늦거나 어긋날 수 있습니다. 감지 전후 0.6초 동안은 계속 가립니다.
- CPU만 쓰면 10분짜리 영상에 대략 15~30분 걸립니다. GPU를 쓰면 5분 안팎입니다.
